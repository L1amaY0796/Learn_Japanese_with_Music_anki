# What is this app for?
This app is designed for Japanese learner to learn Japanese with music.
You can search any jpop song, the app will fetch the lyrics, tokenizing the lyrics into words.
You can click on it to see its explanation about the meaning and syntax rule, and you may also save the word in the lyrics as word cards.
Additionally, the app will automatically arrange review test for you.

# How to use this app?

## Step 1
To enable the searching and explaning function you'll need to apply for two FREE API key for yourself.

1. Genius API : https://genius.com/api-clients
use FB/twitter/google to sign in -> click *new API client*

And then you will see four blank rows, you can follow my instruction to setup your API key : 
* APP name : any (you can fill in *uta learning* if you have no idea about the name)
* Icon url : leave it blank
* App website url : https://github.com/AlanFu1018/Learn_Japanese_with_Music
* Redirect url : leave it blank
And finally, click *save*. You will see your own API client.

Click on *Generate Access Token* and copy it.

2.Gemini API : https://aistudio.google.com/api-keys
click on *create API key button* which you may find on the right of the cornerw -> click *create key*
and you will be able to copy the api key then

## Step 2
When you done installing the uta learning app, click *menu button* and go to the *Settings* page.
Fill in the Genius API Token and Gemini API key you just applied.

And well done. You can learn Japanese words from any jpop song now!
